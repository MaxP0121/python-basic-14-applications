## 使用說明

- **時間分配**：讀題與設計 20 分鐘 → 實作約 2 小時 → 測試與整理 20–30 分鐘。超過 3 小時就停，沒做完的移到隔天開頭。
- **先基本、再進階**：每天先完成「基本要求」；進階挑戰是選做，有餘力再挑。
- **自己寫**：不要先讓 AI 產生程式碼。卡住超過 20 分鐘再去查文件或問，寫完可以丟給 Claude review。
- **留紀錄**：每天存成 `day01_guess_number.py` 這類檔名，放進這個 repo，14 天後就是一份小作品集。
- **測試習慣**：每個題目都試幾個「故意輸入錯誤」的情況，確認程式不會直接當掉。

## 第一週：基礎語法與資料結構

### Day 1｜猜數字遊戲（約 1.5 小時）

**題目**：電腦隨機選 1–100 的整數，玩家輸入猜測，程式回覆「太大」或「太小」，直到猜中為止。

**必學語法**：`import`、`random.randint()`、`input()` 與 `int()` 型別轉換、`while` 迴圈與 `break`、`if / elif / else`、`try / except ValueError`

**基本要求**

1. 用 `random.randint` 產生答案。
2. 猜中後顯示總共猜了幾次。
3. 輸入不是數字或超出 1–100 時，提示重新輸入，不能讓程式當掉。
4. 遊戲結束後詢問「再玩一次？(y/n)」。

**進階挑戰**

- 加入難度選擇：簡單 1–50、普通 1–100、困難 1–1000，並限制最多猜幾次。
- 反過來：你心裡想一個數字，讓電腦用二分法來猜。

### Day 2｜凱薩密碼與密碼產生器（約 2 小時）

**題目**：寫一個小工具，選單有三個功能：加密、解密、產生隨機密碼。

**必學語法**：`def` 與 `return`、字串索引與切片、`str.isalpha()` / `str.isupper()`、`ord()` / `chr()`、`%` 取餘數、`string` 模組、`random.choice()` / `random.shuffle()`、`str.join()`

**基本要求**

1. 寫 `encrypt(text, shift)` 與 `decrypt(text, shift)` 兩個函式，英文字母依位移量平移，大小寫分開處理，`z` 往後要繞回 `a`。
2. 非英文字母（空白、數字、標點、中文）維持原樣。
3. 寫 `generate_password(length)`，產生含大寫、小寫、數字、符號的密碼，且每一類至少出現一次。

**進階挑戰**

- 暴力破解：只給密文，列出 25 種位移結果。
- 為密碼評分：依長度和字元種類給出「弱／中／強」。

### Day 3｜房貸攤還計算機（約 2 小時）

**題目**：輸入貸款金額、年利率、年限，計算每月本息平均攤還的月付金，並印出攤還表。

月付金公式（月利率 $r$、總期數 $n$、本金 $P$）：

$$PMT = P \cdot \frac{r(1+r)^n}{(1+r)^n - 1}$$

**必學語法**：函式參數與預設值、`for` 搭配 `range()`、算術運算子與 `**` 次方、f-string 格式化（`:,.0f` 千分位、`:>10` 靠右對齊）、`round()`

**基本要求**

1. 把公式寫成函式 `monthly_payment(principal, annual_rate, years)`。
2. 用 `for` 迴圈印出每期：期數、月付金、利息、本金、剩餘本金。
3. 用 f-string 對齊欄位，金額加千分位、取到整數。
4. 最後印出總利息支出。

**進階挑戰**

- 加入「本金平均攤還」，並排比較兩種方式的總利息。
- 模擬第 N 年提前還款 X 元後，剩餘期數或月付金的變化。

### Day 4｜英文單字卡測驗器（約 2 小時）

**題目**：自己準備一份 `words.csv`（欄位：`word,meaning`，至少 20 個字，可以用雅思單字），程式隨機出題測驗。

**必學語法**：`list`、`dict`、`with open()` 讀檔與 `encoding`、`csv.DictReader`、`random.sample()`、`str.strip()` / `str.lower()`、`list.append()`、`len()`

**基本要求**

1. 用 `csv` 模組讀檔，存成 `list` of `dict`。
2. 每輪隨機抽 10 題（不重複），顯示中文、讓使用者輸入英文。
3. 比對時忽略大小寫與前後空白。
4. 結束後顯示分數，並列出答錯的字和正確答案。

**進階挑戰**

- 把答錯的字寫進 `wrong.csv`，下次可以選「只練錯題」。
- 加入「英翻中」選擇題模式，選項從其他單字隨機抽出。

### Day 5｜文章字頻統計（約 2 小時）

**題目**：讀入一篇英文文章（`.txt`，例如一篇經濟學人或 Fed 聲明稿），統計最常出現的單字。

**必學語法**：`str.split()`、`str.translate()` 或 `str.replace()`、`set`、`dict.get()` 計數、`sorted()` 搭配 `key=lambda`、`reverse=True`、`collections.Counter`、切片取前 N 名

**基本要求**

1. 全部轉小寫，去除標點符號。
2. 先「不用」`Counter`，自己用 `dict` 計數。
3. 依次數由高到低，印出前 20 名與出現次數。
4. 排除停用字（the、a、of、and 等，自己建一個 `set`）。

**進階挑戰**

- 改用 `collections.Counter` 重寫，比較行數差異。

**基本要求**

1. 選單功能：新增、列出、標記完成、刪除、離開。

### Day 7｜井字遊戲（約 2.5 小時）

**題目**：兩位玩家輪流在 3×3 棋盤下 O 和 X，先連成一線者獲勝。

**必學語法**：二維 list 與巢狀索引 `board[r][c]`、巢狀 `for`、list comprehension（`[[" "] * 3 for _ in range(3)]`）、`all()` / `any()`、`str.split()` 解析輸入、函式回傳不同狀態

**基本要求**

1. 用二維 list 表示棋盤，寫 `print_board(board)` 印出棋盤。
2. 玩家輸入列與行（例如 `1 3`），檢查格子是否已被佔用或超出範圍。
3. 寫 `check_winner(board)`，判斷橫、直、兩條斜線；棋盤下滿無人勝則平手。

**進階挑戰**

- 加入電腦玩家：先隨機下，再改成「能贏就贏、對手要贏就擋」的規則。
- 把棋盤大小改成 N×N、連 K 子獲勝，看你的 `check_winner` 能不能直接沿用。

### Day 11｜生命遊戲（約 2.5 小時）

**題目**：實作 Conway's Game of Life，在終端機上顯示細胞演化。

規則：活細胞周圍有 2 或 3 個活鄰居則存活，否則死亡；死細胞周圍剛好 3 個活鄰居則復活。

**必學語法**：巢狀迴圈、索引邊界判斷、list comprehension 或 `copy.deepcopy()` 建立新 grid、`%` 環狀索引、`time.sleep()`、`print(end="")`、`"".join()`

**基本要求**

1. 用 20×20 的二維 list 表示世界，隨機初始化約 25% 的活細胞。
2. 寫 `count_neighbors(grid, r, c)`，正確處理邊界（邊角的格子不要超出索引）。
3. 寫 `next_generation(grid)`，回傳新的 grid，不能邊算邊改原本的 grid。
4. 用 `time.sleep` 連續顯示 50 代，活細胞印 `■`、死細胞印 `·`。

**進階挑戰**

- 改成上下左右相連的環狀世界（用 `%` 處理）。
- 偵測世界進入穩定或週期循環時自動停止。
- 從檔案讀入經典圖形（例如滑翔機 glider）。

### Day 12｜蒙地卡羅股價模擬（約 2.5 小時）

**題目**：用幾何布朗運動模擬股價路徑，估計一年後股價的分布。

$$S_{t+1} = S_t \cdot \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)\Delta t + \sigma\sqrt{\Delta t}\,Z\right], \quad Z \sim N(0,1)$$

**必學語法**：`math.exp()` / `math.sqrt()`、`random.gauss()`、巢狀 `for`、`sum()` / `sorted()`、自己實作平均數與分位數函式、`statistics` 模組（驗算用）、`time.perf_counter()`

**基本要求**

1. 參數：初始股價 $1000$、年化報酬 $\mu = 8\%$、年化波動 $\sigma = 25\%$、$\Delta t = 1/252$、$252$ 個交易日。
2. 只用 `random.gauss` 與 `math`，不用 numpy，模擬 1,000 條路徑。
3. 自己寫函式計算一年後股價的平均數、標準差、中位數，以及 5% 與 95% 分位數。
4. 計算一年後股價低於初始價的機率。

**進階挑戰**

- 以模擬結果為一張履約價 1050 的一年期歐式買權定價（用無風險利率折現），再對照 Black-Scholes 公式。
- 改用 numpy 向量化重寫，比較執行時間。

### Day 13｜純 Python 均線回測（約 3 小時）

**題目**：不用 pandas，回測一檔台股的均線交叉策略。

**必學語法**：`csv` 讀檔與型別轉換、list 切片計算均線、`zip()`、用布林變數記錄持有狀態、`//` 整除計算股數、`max()` 追蹤高點算回撤、把邏輯拆成多個函式

**基本要求**

1. 準備資料：一檔股票（例如 2330）近 2 年日收盤價，存成 `price.csv`（欄位 `date,close`）；可以手動從證交所網站下載，或用 FinMind 抓好存檔。
2. 用 `csv` 讀檔，自己寫 `moving_average(prices, window)` 算出 5 日與 20 日均線。
3. 規則：5 日線向上穿越 20 日線全額買進，向下穿越全部賣出；初始資金 100 萬，不考慮零股。
4. 輸出：交易紀錄、最終資產、總報酬率、交易次數、勝率，並和買進持有比較。

**進階挑戰**

- 計算最大回撤（MDD）。
- 把均線天數當參數，跑多組組合找出表現最好的一組，並想想這樣做有什麼過度擬合的風險。
- 用 pandas 重寫一次，核對兩個版本的結果是否完全一致。

### Day 14｜股價爬蟲 + 串接回測（約 3 小時）

**題目**：寫爬蟲自動抓股價，產出 Day 13 能直接讀的 `price.csv`，完成一條「抓資料 → 回測」的流程。

**必學語法**：`pip install`、`requests.get()` 與 `params`、`response.json()`、`str.replace()` 清理數字、`datetime` 日期轉換、`time.sleep()`、`try / except requests.RequestException`、`import` 自己寫的模組

**基本要求**

1. 用瀏覽器開發者工具（Network 分頁）找到證交所「個股日成交資訊」回傳的 JSON 網址。
2. 用 `requests` 依月份抓取指定股票近 24 個月的資料，每次請求間 `time.sleep` 數秒，避免被封鎖。
3. 解析 JSON，處理民國年轉西元年、去掉數字中的千分位逗號，輸出 `date,close` 格式的 CSV。
4. 把 Day 13 的回測改寫成可 `import` 的函式，寫一個 `main.py`：輸入股票代號 → 爬資料 → 回測 → 印出結果。

**進階挑戰**

- 網路錯誤時自動重試 3 次，失敗就記錄並略過。
